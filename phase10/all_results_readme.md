# All Results Archive — README

This archive `all_results.tar.gz` contains a consolidated snapshot of non-sensitive project result artifacts created for convenience. It was generated by the packaging step in Phase 10.

Included directories (if present):

- `figures/` — generated figures and previews
- `datasets/` — input datasets used for analyses
- `models/` — model artifacts and checkpoints
- `scripts/` — reproduction and analysis scripts (including `scripts/plotting`)
- `plots/` — plotting configuration and presets
- `phase5/`, `phase8/`, `phase9/`, `phase10/` — run manifests, reproducibility docs, and packaging artifacts

Exclusions:

- `phase7/secure/` is deliberately excluded to avoid publishing sensitive transcripts or uncontrolled exploit material. If you have explicit permission to include those files, copy them manually into `phase10/package/phase7_secure/` and re-run packaging.

How the archive was created:

```bash
bash -lc "tar -czf phase10/all_results.tar.gz --ignore-failed-read figures results datasets models scripts plots phase5 phase8 phase9 phase10"
```
